# StudyTrack

StudyTrack is a beginner-friendly student learning dashboard. It is designed as a project for learning Git and GitHub while gradually adding real features.

## Current version

- Student progress dashboard
- Study material upload for `.txt` and `.md`
- Local starter summary
- Quick quiz
- Practice/try-work section
- Progress saved in the browser with `localStorage`

## Run it

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Git practice

From this project folder:

```bash
git status
git add .
git commit -m "Create StudyTrack starter dashboard"
git push
```
